# Calculadora en PSeInt

Este proyecto es una calculadora básica hecha en el pseudolenguaje de programación **PSeInt**. Permite realizar operaciones simples como suma, resta, multiplicación y división.

## Características

- Menú interactivo para elegir la operación.
- Soporte para las siguientes operaciones:
  - Suma
  - Resta
  - Multiplicación
  - División (con verificación para evitar división entre cero)
